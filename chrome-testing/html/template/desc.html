<desc>

Descriptive element — never rendered visually. Provides a long description for accessibility (screen readers). Each card shows the host shape rendering + the markup used.

desc on root svg
<svg> <desc>A simple red rectangle...</desc> <rect .../> </svg>
desc child of circle
<circle cx="100" cy="60" r="50"> <desc>A teal circle...</desc> </circle>
desc child of g
<g> <desc>Three overlapping circles...</desc> <circle.../> ... </g>
desc with id + aria-describedby
<rect aria-describedby="rect-desc"> <desc id="rect-desc">...</desc> </rect>
multiple desc with lang
<circle> <desc lang="en">...</desc> <desc lang="fr">...</desc> <desc lang="de">...</desc> </circle>
desc never renders visually
<polygon ...> <desc> This text is NOT visible... </desc> </polygon>

Note: <desc> is a never-rendered element (UA sets display:none). Its content is exposed to screen readers and accessibility APIs. The host shapes above all render; only the desc text is invisible.
