<feOffset>

Shifts the input image by dx/dy in user units. Commonly used to build manual drop-shadows by merging offset shadow with original.

dx="0" dy="0"
(no shift)
dx="10" dy="0"
(right)
dx="0" dy="10"
(down)
dx="12" dy="12"
(diagonal)
dx="-10" dy="-10"
(upper-left)
shadow: offset +
merge with source
dx="30" dy="0"
(large offset)
