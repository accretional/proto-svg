<metadata>

Descriptive element — never rendered visually. Carries machine-readable metadata (Dublin Core, RDF, custom data). The host shape is always visible; the metadata element is hidden by UA.

Dublin Core inside metadata
<svg> <metadata> <dc:creator>...</dc:creator> <dc:title>...</dc:title> <dc:date>...</dc:date> </metadata> </svg>
RDF metadata
<metadata> <rdf:RDF> <rdf:Description> <dc:format>image/svg+xml</dc:format> <dc:type>StillImage</dc:type> </rdf:Description> </rdf:RDF> </metadata>
metadata: plain text content
<metadata> version: 1.0; license: CC-BY-4.0; </metadata>
metadata with id attribute
<metadata id="doc-meta"> <dc:creator>Design Team</dc:creator> <dc:rights>Copyright...</dc:rights> </metadata>
metadata never renders visually
<metadata> <!-- NEVER rendered on canvas --> <invisible-element>... </invisible-element> </metadata> <rect .../> <!-- renders -->
metadata with data-* attrs
<metadata data-schema="1.0" data-source="proto-svg" data-generated="2026-06-22"> ... </metadata>

Note: <metadata> is a never-rendered element (UA sets display:none). It carries machine-readable structured data (RDF, Dublin Core, custom schemas). The host shapes above all render; only the metadata content is hidden. data-* attributes are expressly allowed on metadata per the SVG 2 spec (§5.9).
